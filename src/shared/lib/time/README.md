# shared/lib/time

Чистые функции над строками `YYYY-MM-DD` / `HH:mm`: перевод в минуты и обратно, проверка реальной даты (`isCalendarDate`), сдвиг даты, день недели,
«сейчас» в заданном или локальном часовом поясе (`zonedNow`), проверка IANA-пояса.

Можно: форматы и арифметика времени без бизнес-правил.
Нельзя: рабочий день, длительности, пересечения броней — это `entities/booking`.
